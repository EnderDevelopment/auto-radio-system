# AutoRadio System

Stream YouTube music in your FiveM server with this AutoRadio System.

## Features

- Play YouTube music in the server
- Adjust the volume of the radio
- Save radio settings to the database

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the AutoRadio System from [GitHub](https://github.com/EnderDevelopment/auto-radio-system)
2. Extract the files into your FiveM server's resources folder
3. Add `start auto-radio-system` to your server.cfg file

## Usage

- Use the `/radio` command to open the radio UI
- Enter a YouTube link and adjust the volume
- Click the play button to start the radio

## Configuration

The AutoRadio System can be configured in the `config.lua` file. You can adjust the radio distance, maximum volume, and UI settings.
